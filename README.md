Budget Tracker
A polished monthly budget tracker built with vanilla JavaScript and Bootstrap.

Features
Add new expenses with a name, amount, and category.
Automatically calculate the running monthly total.
Render expense rows in a clean table layout.
Use modular JavaScript with ES module imports and exports.
Responsive Bootstrap-based interface for desktop and mobile screens.
Budget status logging for monthly tracking.
Files
index.html — main UI layout and Bootstrap styling
script.js — app behavior and the add-expense flow
budget.js — exported calculation and rendering utilities
Local usage
Open index.html in a browser, or serve the folder with a lightweight local web server if needed.
